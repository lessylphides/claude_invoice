# 매입 캘린더

스마트폰 카메라로 **구매 영수증이나 거래명세서를 찍으면** Claude가 거래처, 날짜, 품목, 수량, 단가, 금액을 읽어서 **자동으로 분류해 입력**하는 캘린더 형식의 매입 장부 웹앱(PWA)입니다.

## 기능

| # | 요구사항 | 구현 |
|---|---|---|
| 1 | 해당 월 총 매입 금액 | 상단 카드에 월 합계, 건수, 세금계산서 미발행 금액 표시 |
| 2 | 월 합계를 거래처별·항목별로 보기 | 달력 아래 `거래처별 / 항목별 / 세금계산서·카드` 버튼. 줄을 누르면 품목별로 펼쳐짐 |
| 3 | 날짜칸에 그날 합계 | 날짜칸에 축약 금액 표시(예: `23.6만`). 세금계산서 미발행 건이 있는 날은 주황 점 |
| 4 | 날짜를 누르면 매입처별·항목별 | 날짜 상세 화면의 `매입처별 / 항목별` 탭 |
| 5 | 매입처별 세금계산서·카드 체크박스 | 매입처 카드마다 `세금계산서`, `카드` 체크박스. 세금계산서를 고르면 `발행 받음` 체크박스가 나타남 |
| 6 | 세금계산서 발행/미발행 금액 | 날짜 상세와 월 `세금계산서·카드` 탭에 발행/미발행 합계, 미발행 거래처 목록 |
| 7 | 품목을 누르면 가격 추이 | 품목(📈)을 누르면 지금까지의 단가 추이 그래프, 최근·평균·최저·최고 단가, 이력 표. 거래처별로 걸러 보기 가능 |

그 밖의 기능
- 앨범에서 여러 장을 골라 한 번에 인식하기, 사진 없이 직접 입력하기
- 인식 결과는 저장하기 전에 사진과 비교하며 고칠 수 있음. 품목 합계와 문서 합계가 다르면 경고
- 거래처 이름 자동완성. `(주)`, 띄어쓰기 등이 달라도 같은 거래처나 품목으로 묶음
- 이번 달 CSV 내보내기(엑셀용), 전체 백업과 복원(JSON)
- 홈 화면에 추가해서 앱처럼 쓰기(PWA), 다크 모드

## 사용법

1. `⚙ 설정`에서 **Claude API 키**를 입력합니다([console.anthropic.com](https://console.anthropic.com)에서 발급).
   - 키는 이 기기의 브라우저에만 저장되고 Anthropic API로만 전송됩니다.
   - 인식 모델은 기본값 Claude Opus 5.5이고, 더 저렴한 Sonnet 5.5나 Haiku 5.5로 바꿀 수 있습니다.
2. 아래쪽 **📷 영수증 촬영** 버튼을 누르고 → 촬영 → 인식 결과를 확인한 뒤 **저장**합니다.
3. 달력의 날짜를 누르면 그날의 매입처별·항목별 내역이 나오고, 결제 구분을 체크할 수 있습니다.

> 데이터는 **이 기기의 브라우저(localStorage)** 에 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 `설정 → 전체 백업 파일 저장`으로 백업하세요.

## 개발 / 배포

```bash
npm install
npm run dev      # http://localhost:5173 (같은 와이파이의 휴대폰에서 IP로 접속 가능)
npm run build    # dist/ 에 정적 파일 생성
```

- 카메라 촬영과 PWA 설치는 **HTTPS**(또는 localhost)에서만 동작합니다.
- `main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 GitHub Pages에 자동으로 배포합니다(저장소 Settings → Pages → Source를 *GitHub Actions*로 설정).

## 구조

```
src/
  main.js    달력, 월 요약, 날짜 상세, 가격 추이, 촬영 흐름, 설정
  editor.js  매입 입력/수정 폼, 인식 결과를 초안으로 변환
  ocr.js     사진 축소 → Claude API(비전 + JSON 스키마 구조화 출력)로 추출
  store.js   localStorage 저장소, 결제 구분/세금계산서 상태
  chart.js   가격 추이 SVG 꺾은선 그래프
  sheet.js   하단 시트, 토스트, 로딩 표시
public/      manifest, 서비스워커, 아이콘
```
