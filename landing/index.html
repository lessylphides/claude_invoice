자주 묻는 질문

앱스토어에 없나요?

코스트노트는 웹앱이에요. 설치 파일을 받지 않고 주소로 열어 홈 화면에 추가해 쓰면 돼요. 업데이트도 자동으로 반영돼요.

제 장부는 안전한가요?

장부는 계정별로 암호화된 연결을 통해 저장되고, 본인만 읽고 쓸 수 있어요. 영수증 사진은 인식에만 쓰고 서버에 남기지 않아요.

해킹이나 개인정보 유출이 걱정돼요

코스트노트는 서버를 직접 만들어 굴리지 않고, 세계적으로 검증된 업체의 인프라만 써요. 그리고 털려도 피해가 커지지 않도록 애초에 민감한 정보를 적게 갖는 것을 원칙으로 지켜요.

  • 검증된 업체만 사용해요. 앱과 서버는 전 세계 웹사이트 보안을 맡고 있는 Cloudflare, 계정과 장부는 Supabase(데이터는 서울 리전), 영수증 인식은 Claude 를 만든 Anthropic 공식 API 를 써요. 모두 SOC 2 같은 국제 보안 인증을 받고 정기적으로 외부 감사를 받는 곳이에요. Anthropic 공식 API 로 보낸 사진은 인공지능 학습에 쓰이지 않아요.
  • 카드번호·계좌·주민번호를 받지 않아요. 가입에는 이메일과 비밀번호만 쓰고, 비밀번호는 원래 글자를 알 수 없게 암호화해 저장해요.
  • 영수증 사진은 인식이 끝나면 저장하지 않아요. 남는 건 사장님이 확인하고 저장한 장부 내용뿐이에요.
  • 내 장부는 나만. 데이터베이스 규칙으로 계정마다 자기 장부만 읽고 쓸 수 있어요. 다른 가게의 장부는 서비스 운영자도 앱으로는 볼 수 없게 막혀 있어요.
  • 모든 통신은 암호화(HTTPS)되고, 인공지능 이용 키 같은 비밀 정보는 휴대폰이 아닌 서버에만 보관해요. 앱은 정해진 서버 외에는 데이터를 보낼 수 없도록 막혀 있어요.
  • 코스트노트는 이메일·문자·전화로 비밀번호를 절대 묻지 않아요. 그런 연락은 사기이니 응하지 마세요. 공식 메일은 noreply@costnote.co.kr 에서만 보내요.

사장님도 다른 사이트와 다른 비밀번호를 쓰고, 휴대폰을 잃어버리면 다른 기기에서 비밀번호를 바꿔 주세요. 만에 하나 개인정보 유출이 확인되면 법에 따라 지체 없이 알려 드리고 필요한 조치를 안내해 드릴게요.
